# Student-Performance_Admission-PowerBI-Dashboard


## Project Overview

This project presents a Student Performance & Admission Analysis Dashboard designed to analyze student marks, department performance, gender distribution, monthly admissions, and city-wise student distribution.

## Dashboard KPIs

* **Total Students:** 1,000
* **Average Marks:** 66
* **Highest Marks:** 100
* **Lowest Marks:** 30
* **Total Departments:** 6

## Key Insights

* Analyzed average marks across six departments.
* Visualized student distribution by gender.
* Tracked monthly student admission trends.
* Compared student counts across six cities.
* Added interactive filters for Department, Gender, and City.

## Tools & Skills

* Microsoft Power BI
* Data Visualization
* Dashboard Design
* KPI Analysis
* Interactive Filtering

## Project Objective

The objective of this project is to transform student-related data into meaningful visual insights that can support performance monitoring and admission analysis.
